# RFID-Based Unified Citizen Services Management System

## 📌 Project Overview
This project is an embedded system developed using the LPC2148 (ARM7) microcontroller. It provides multiple citizen services such as PAN details, ATM access, digital voting, and driving license verification using a single RFID card.

## ⚙️ Features
- RFID-based secure authentication
- Password verification with retry mechanism
- Multi-service access using a single card
- LCD interface for user interaction

## 🛠️ Technologies Used
- Embedded C
- LPC2148 Microcontroller (ARM7)
- RFID Module
- UART Communication
- LCD Display

## 🔄 Working Principle
1. User scans RFID card  
2. System verifies the card  
3. User enters password  
4. If authenticated → access granted  
5. User selects required service  

## 🎯 Applications
- Smart governance systems  
- Digital identity platforms  
- Secure access systems
